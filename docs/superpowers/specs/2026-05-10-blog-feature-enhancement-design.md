# 博客系统功能增强设计文档

**日期**: 2026-05-10
**状态**: 已批准

---

## 概述

为静态博客系统增加 4 个高优先级功能：搜索、代码高亮、复制代码按钮、404页面。

---

## 1. 搜索功能

### 1.1 技术方案
- **搜索库**: Fuse.js (客户端模糊搜索)
- **路由**: `/search?q=关键词`

### 1.2 组件结构
| 文件 | 职责 |
|------|------|
| `src/views/Search.vue` | 搜索结果页 |
| `src/components/SearchBox.vue` | 搜索输入框组件 |
| `src/composables/useSearch.js` | 搜索逻辑封装 |

### 1.3 数据流
1. 用户在 Header 输入框输入关键词
2. 路由跳转到 `/search?q=关键词`
3. SearchView 调用 useSearch composable
4. Fuse.js 在 articles 数组中模糊匹配（匹配 title、excerpt、tags、category）
5. 返回匹配结果并高亮关键词

### 1.4 UI 设计
- 搜索框：带图标输入框，placeholder "搜索文章..."
- 结果页：显示匹配数量，文章卡片高亮匹配文字
- 无结果：显示空状态提示 + 建议

---

## 2. 代码高亮功能

### 2.1 技术方案
- **库**: Prism.js (CDN 引入，约 30KB)
- **主题**: Tomorrow Night (暗色主题)
- **语言支持**: JavaScript, TypeScript, HTML, CSS, JSON, Bash

### 2.2 文件变更
| 文件 | 变更 |
|------|------|
| `src/main.js` | 添加 Prism 及其组件引入 |
| `src/style.css` | 添加 Prism 主题样式 |
| `src/views/ArticleDetail.vue` | 渲染后调用 highlight() |

### 2.3 样式主题 (Tomorrow Night)
```css
.token.keyword { color: #c678dd; }
.token.string { color: #98c379; }
.token.comment { color: #5c6370; }
.token.function { color: #61afef; }
```

---

## 3. 复制代码按钮

### 3.1 技术方案
- **API**: 原生 Clipboard API
- **位置**: 代码块右上角
- **反馈**: 点击后显示 "已复制!"，2秒后恢复

### 3.2 交互状态
| 状态 | 外观 |
|------|------|
| 默认 | 半透明隐藏，右上角 |
| 悬停 | 背景显现 |
| 点击后 | 绿色 ✓ + "已复制!" |

### 3.3 文件变更
| 文件 | 变更 |
|------|------|
| `src/style.css` | 添加复制按钮样式 |
| `src/views/ArticleDetail.vue` | 添加复制逻辑和按钮 |

## 5. 实现顺序

1. 404 页面 (最简单，独立)
2. 代码高亮 + 复制按钮 (相关性强)
3. 搜索功能 (需新增组件和路由)
